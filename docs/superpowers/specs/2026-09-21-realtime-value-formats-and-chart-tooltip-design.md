# 实时值多进制显示与曲线悬浮设计

## 目标与范围

增强设备点位实时值弹窗：同时显示十进制、二进制和十六进制值；曲线按每秒一个采样点从右向左滚动；鼠标移动到曲线上时显示最近采样点的时间和值。

本次沿用现有 WebSocket 订阅、原生 Canvas、时间窗口和浏览器内存样本，不修改后端接口、采集逻辑、WebSocket 协议或持久化模型，不增加第三方前端依赖。

## 多进制实时值

弹窗实时读数区域显示三行：十进制、二进制和十六进制。

- `Bool` 映射为整数 `0` 或 `1`，二进制使用 `0b` 前缀，十六进制使用 `0x` 前缀。
- `Int16`、`UInt16`、`Int32` 和 `UInt32` 按数值转换。负整数使用负号加绝对值进制表示，例如 `-2` 显示为 `-0b10` 和 `-0x2`，不显示补码。
- `Float32` 和 `Double` 保留接收到的十进制值，二进制和十六进制显示 `—`，避免与 IEEE 754 位模式混淆。
- 空值、非有限数值或无法识别的值显示 `—`。

更新时间和连接状态继续显示在读数区域。每次收到匹配当前点位的 WebSocket value 消息时立即更新三种格式。

## 秒级采样与滚动时间轴

浏览器保存当前连接收到的最新有效数值。连接正常且已有有效值时，每秒整点附近向样本序列追加一次当前最新值，以浏览器当前时间作为采样时间。同一自然秒最多保留一个点，避免消息到达与定时器造成重复。

WebSocket 消息负责更新最新值，不直接为每条消息追加曲线样本。WebSocket 断开时停止秒级采样；重连并收到新的有效值后恢复采样，并使用新的曲线段编号，曲线不跨越断线区间连接。

曲线横轴继续覆盖所选的 1、5、10 或 30 分钟窗口。右边界是当前浏览器时间，横轴刻度显示本地时间 `HH:mm:ss`。每秒重绘后，旧采样点相对横轴向左移动，超出 30 分钟保留范围的样本从内存删除。

## 鼠标悬浮交互

Canvas 监听 `pointermove` 和 `pointerleave`。指针位于绘图区时，根据横坐标查找时间距离最近的可见样本，并记录为当前悬浮样本。

重绘时在该样本位置绘制竖向辅助线和高亮圆点，并在绘图区内绘制提示框。提示框包含本地时间 `HH:mm:ss` 和十进制值；提示框根据指针位置自动选择左右方向，避免超出 Canvas。指针离开 Canvas、切换点位或关闭弹窗时清除悬浮状态。

悬浮只选择真实保存的秒级样本，不选择为时间窗口边界生成的视觉锚点，也不在断线区间生成虚拟样本。

## 组件边界

- `web/device.html`：把单一实时值字段替换为十进制、二进制和十六进制字段。
- `web/js/device.js`：负责格式转换、最新值状态、秒级采样、绝对时间刻度、悬浮命中检测和 Canvas 提示绘制。
- `web/css/app.css`：设置多进制读数布局，并保持小屏可读。
- `web/embed_test.go`：验证新增字段和关键交互行为存在，防止恢复消息驱动的不规则采样。

## 异常与生命周期

- 非数值、`NaN` 和无穷值可以更新文本为不可用状态，但不进入曲线。
- 关闭弹窗时清理 WebSocket、重连定时器、秒级采样/重绘定时器、最新值、样本和悬浮状态。
- 旧 WebSocket 会话继续通过现有会话编号隔离，不能更新新打开的点位弹窗。
- Canvas 尺寸变化或时间窗口切换后立即重绘，并使用当前悬浮坐标重新计算命中点。

## 验证

嵌入资源测试覆盖：

- 十进制、二进制和十六进制字段存在；
- 整数/布尔值进制格式函数和浮点禁用规则存在；
- 秒级采样函数由一秒定时器调用；
- 横轴使用 `HH:mm:ss` 本地时间；
- Canvas 注册 `pointermove`、`pointerleave`，并绘制辅助线、点和提示框；
- WebSocket 消息只更新最新值，不直接追加不规则曲线样本。

运行 `go test ./web -count=1` 和 `go test ./... -count=1`。浏览器人工验收覆盖整数、负整数、布尔值、浮点值、恒定值、断线重连、窗口切换、鼠标悬浮和高分屏显示。

## 完成标准

实时值弹窗能正确显示支持的数据格式；曲线连接期间每秒生成一个采样点并以本地时间轴从右向左滚动；鼠标悬浮能稳定显示最近采样点的时间与值；断线期间不补点或跨段连线。
